Snapshot: Phase 2 feature branch, 2026-11-07. Research source/evidence limitations remain in the [evidence register](README.md#evidence-register) and [RC synthesis](RESEARCH_SYNTHESIS.md). Decision IDs below are the existing D01–D17 in the [decision ledger](SCIENTIFIC_DECISIONS.md); [ADR 0003](../adr/0003-spice-geometry.md) records this milestone's selections without rewriting historical research statuses.

Each row is a scoped requirement. Classification is **implemented**, **verified**, **deferred**, **unresolved**, or **not applicable**. Implemented means code exists; verified is reserved here for the precisely scoped external reference agreement in RC-09, not universal scientific validity. Software coverage and scientific evidence are separate columns. Empty evidence is explicitly absent, not a successful constraint.

## Phase 2 boundary

This milestone implements scoped parts of RC-02, RC-03, RC-06, RC-07, RC-09, RC-13 and RC-14. It adds a narrowly verified RC-09 published-reference consistency case. RC-01 and RC-04–RC-12 product/scientific algorithms beyond these input geometry pieces remain deferred as explicitly itemized above. Exact terrain/datum uncertainty, apparent/disc policy and external surface-observer reference cases remain unresolved or deferred; neither a kernel hash nor passing pytest closes them.

No electrical-power, RF reliability, landing certification, optimization completeness, or NASA endorsement requirement is applicable to this geometry milestone. Those claims are unsupported, not implied outcomes. See [scientific limitations](../science/modeling-principles.md) and [verification evidence](../validation/spice-geometry-validation.md).
