# Manifests

[spice-de440.json](spice-de440.json) records the five actually retrieved/hashed NAIF kernels for the scoped Phase 2 demonstration, including source URLs, sizes, versions, order, coverage notes and retrieval date. No binaries are tracked. See [SPICE integration](../../docs/science/spice-integration.md) for explicit acquisition and verification; default tests are offline. The [data policy](../README.md) governs future terrain and derived-data records.
